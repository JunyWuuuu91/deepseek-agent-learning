这页跑的是 [迷你 Router–Worker](/learn/31-mini-router/) 里的 `apply`。浏览器不保存密钥，也不发出网络请求。预设事件和你自己写的事件走同一套规则：快路径由代码丢掉或扇出，慢路径才接单。自动播放会停在待决定事项上。

<Lab client:load />

状态在 `src/lib/routerMachine.ts`。页面只负责记录每一步，方便上一步和重来。公开原型的面板优先展示等人处理的工单；这里把问题、验收和失败放在右侧，件数就是角标。

## 练习

1. 按「群聊闲谈 → GitHub 点名 → 同一线程的 CI」走一遍，再选「改成 480px」和「验收通过」。
2. 重来后选「先不改」。比较工单是已完成还是已丢弃，订阅还在不在。
3. 打开开发者工具的网络面板，确认这些点击没有请求。
